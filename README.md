# Página promocional FrammelGYM

## Descripción

> El objetivo de este proyecto es crear una página promocional para el centro de salud de FrammelGYM para así impulsar el negocio y generar presencia y visibilidad en la web.

## Tecnologías

- React 19.2

## Requisitos previos

- Tener instalado Node.js

## Instalación 


```bash
# 1. Clona el repositorio
git clone https://github.com/yepetopg/FrammelGym.git

# 2. Accede a la carpeta del proyecto
cd FrammelGym

# 3. Instala las dependencias
npm install

# 4. Ejecuta el proyecto
npm start

```

Abre el link [http://localhost:3000](http://localhost:3000) en tu navegador
