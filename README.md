# Página promocional FrammelGYM

## Descripción

El objetivo de este proyecto es crear una página promocional para el centro de salud de FrammelGYM para así impulsar el negocio y generar presencia y visisbilidad en la web.

## Tecnologías

- React 19.2

## Instalación 

1. Clonar el repositorio
2. Accede a la carpeta del proyecto
3. Instala las dependencias
4. Ejecuta el proyecto
5. Abre el link del proyecto [http://localhost:3000](http://localhost:3000)

```bash
git clone https://github.com/yepetopg/FrammelGym.git
cd FrammelGym
npm install
npm start

```
